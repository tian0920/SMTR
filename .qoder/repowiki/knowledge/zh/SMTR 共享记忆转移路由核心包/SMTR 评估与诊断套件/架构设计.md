模块以 `__init__.py` 暴露顶层 API（`TaskEvaluationConfig`、`evaluate_task_execution`、`summarize_run`），内部按职责拆分为若干独立子文件，彼此之间不互相 import，统一依赖上层 `smtr.runtime`、`smtr.experiment.schemas`、`smtr.counterfactual.schemas` 与 `smtr.router.*`：
- 任务级评测：`task_evaluation.py` 通过 `_environment_factory` 动态加载 `ToyEnvironment` / `ToolEnvironment`，调用 `run_episode` 收集 episode 指标并汇总为 JSON；`logging.py` 将 `SMTRState` 序列化为可读文本。
- 方法对比统计：`paired_statistics.py` 基于 `ComparisonRunRecord` 按 `base_episode_id` 聚合，计算 success / exposure / positive/negative_transfer / opportunity_capture / safety_preservation 等指标，并用 bootstrap 给出配对差异的置信区间；`group_effects.py`、`order_sensitivity.py`、`temporal_integrity.py`、`interaction_audit.py`、`stale_propagation.py`、`prefix_intervention_audit.py` 围绕同一 schema 做专项分析。
- 反事实/转移学习评测：`splitters.py` 定义 `EvaluationSplitSpec`（episode / scenario_family / environment_regime / target_memory_family / prefix_structure_family / factor_combination / surface_variant / temporal_round）并实现组级打散切分；`compositional_splits.py` 组合严格模式与组合模式；`feature_ablation.py` 用 `HashingTransferFeatureEncoder` 的不同 `feature_block` 训练 `FourOutcomeTransferCritic` 并报告 best single block 与 full model gain；`leakage_scanner.py` 扫描编码 token 是否泄漏 forbidden 字段。
- 门控/路由诊断：`gate_diagnostics.py` 从 `DecisionRecord` 的 tau_mean / tau_lcb / negative_risk_* 构建单调漏斗并断言正例漏斗单调性；`ablation_gates.py`、`shortcut_diagnostics.py`、`static_set_diagnostics.py`、`experiment_integrity.py`、`group_effects.py` 等补充不同视角的诊断。
依赖方向单向向外：本模块只消费运行时状态与实验记录，不反向修改它们，所有输出均为 dict / Pydantic BaseModel / dataclass，便于序列化到磁盘。
