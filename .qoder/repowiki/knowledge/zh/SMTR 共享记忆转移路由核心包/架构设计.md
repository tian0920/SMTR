本包是 SMTR 的顶层装配层，子模块通过 CLI 中的命令函数按阶段串联：
- 数据准备：memory.store + memory.seed_memories 初始化 SQLiteSharedMemoryRepository；marble.* 负责数据集清单与真实轨迹。
- 策略/路由装配：policy.manifests 持久化 ContinuationPolicyManifest（no-share / frozen-critic / risk-constrained exploration），router.factory.build_router 根据 mode 与 critic checkpoint 构建具体路由器；robust 作为可选扩展注入 LCB/UCB 估计。
- 离线反事实收集：counterfactual.* 在 runtime.graph.run_episode 中捕获 DecisionPoint，由 PairedRolloutCollector 以 share/withhold 双分支回放并写入 PairedRecordWriter。
- 证据入库与 Critic 训练：memory.paired_transfer_evidence.PairedTransferEvidenceIngestor 将 paired record 转为执行证据入库，router.transfer_critic.FourOutcomeTransferCritic 基于特征编码器拟合四分类模型。
- 实验编排：experiment.runner.ComparisonRunner 读取 ExperimentConfig，并行运行多种方法（含消融变体）并输出 runs.jsonl / summary.json。
- 运行时服务：runtime.api_server 暴露 FastAPI OpenAI 兼容接口，runtime.fake_llm/real_llm 提供推理后端。
跨子模块的数据契约集中在 smtr.memory.schemas（MemoryRoutingCard、ProcedurePayload）与 smtr.counterfactual.schemas（DecisionPoint、PairedRecord），并通过 JSON 工件（checkpoint、metadata.json、runs.jsonl）在进程间传递。
