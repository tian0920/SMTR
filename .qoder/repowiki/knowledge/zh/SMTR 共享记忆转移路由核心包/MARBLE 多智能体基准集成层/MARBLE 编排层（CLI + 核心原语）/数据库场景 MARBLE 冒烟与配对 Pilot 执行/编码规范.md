- 所有对外入口统一以 `*` 命名参数形式声明，并在函数首行调用 `assert_marble_artifact_path(output_dir)` 校验输出路径合法性。
- 持久化输出一律使用 `json.dumps(..., indent=2, sort_keys=True) + "\n"` 写入 `.json` 文件，并以 `encoding="utf-8"` 显式指定编码。
- 通过 `canonical_digest` 对 system/task/tools/memory 各段及完整 agent input 计算指纹，用于 share/withhold 分支的一致性断言而非直接比较原始内容。
- 运行时前置检查统一走 `run_database_runtime_preflight(marble_root=...)`，若 `preflight.ready` 为假则收集 blocking failures 名称抛出 `RuntimeError`。
- 每个运行产出一个包含 `run_id`、时间戳与随机后缀的标识符，由 `_run_id` 辅助函数按 `task-{id}_branch-{branch}_seed-{seed}_ts-{iso}_{uuid}` 格式拼接生成。
