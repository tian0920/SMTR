- Pydantic 模型统一设置 `model_config = ConfigDict(frozen=True)`，使能力与任务规格不可变。
- CLI 子命令采用 `parser.add_parser(name).add_argument(...)` 链式声明参数，并在 `args.command == "..."` 分支内直接调用对应函数，不在子 parser 上绑定 action。
- 所有 JSON 输出均通过 `json.dumps(..., indent=2, sort_keys=True) + "\n"` 写入，且显式指定 `encoding="utf-8"`。
- 对外暴露的写路径先执行 `output.parent.mkdir(parents=True, exist_ok=True)` 再写入，确保目录存在。
