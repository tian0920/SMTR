本模块由三个职责清晰的文件组成：
- `cli.py` 作为唯一入口（`python -m smtr.marble.cli`），通过 `argparse` + `add_subparsers` 注册约 16 个子命令（inspect-dataset、create-splits、run-database-b0-smoke、collect-database-trajectories、train-critic、run-evaluation、integrity-audit 等），每个子命令仅做参数解析与调用下游 `smtr.marble.*` 包中的函数/类，自身不实现业务逻辑。
- `task_provider.py` 提供 `MarbleTaskProvider` 与 `MarbleTaskSpec`（Pydantic frozen model），基于“冻结的 dataset manifest + JSONL 源文件”按 task_digest 或 split 加载真实任务，是 CLI 中 `generate-paired-records`、`build-database-candidates` 等命令的数据来源。
- `capabilities.py` 定义 `MarbleScenarioCapability` / `MarbleCapabilityManifest` 两个 frozen Pydantic 模型，并通过 `inspect_capabilities` 扫描 `MARBLE_BENCHMARK_FILES` 判定各 scenario 的环境/隔离/评估能力，供 `inspect-capabilities` 子命令输出。
依赖方向单向向外：CLI → task_provider/capabilities → 其余 `smtr.marble.*` 子包；三者之间无循环引用。所有持久化产物统一使用 `Path.write_text(..., encoding="utf-8")` 并以 `sort_keys=True` 序列化 JSON。
