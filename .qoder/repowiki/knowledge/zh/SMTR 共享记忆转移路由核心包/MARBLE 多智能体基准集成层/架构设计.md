本包是 SMTR 对 MARBLE 基准的集成外壳，按职责拆分为三个协作层次：
- 编排层（cli.py + evaluation/training/paired_records/real_*）：单入口 `python -m smtr.marble.cli` 提供 inspect-dataset / create-splits / generate-paired-records / collect-database-trajectories / train-critic / run-evaluation / integrity-audit 等子命令，将 dataset → split → paired-records → trajectory → memory → candidate → real-pairs → training → evaluation 的流水线串起来。
- 环境隔离层（environment/）：通过 `MarbleDatabaseEnvironment` 与 `bundle_from_manifest_task` 把任务初始状态打包到分支工作区，由 `database_fingerprint`/`database_rebuild` 保证可重建性，供 paired-smoke/pilot 使用。
- 结果评估层（outcome/）：定义 `MarbleOutcome` / `MarbleOutcomeEvaluator` 协议，`scenarios/database.py` 实现 database 场景的结果判定，被 `MarbleExperimentRunner.run()` 调用。
跨子模块的数据契约全部通过 JSON 工件（dataset_manifest.jsonl、split_manifest.jsonl、paired_records.jsonl、trajectory_index.jsonl、memory_pool.jsonl、candidate_manifest.jsonl、checkpoint.bin）经 `Path` 路径传递；CLI 是唯一组装点，子模块之间不直接互相 import，仅通过 manifest 文件约定耦合。
